## Context

Three documents state incompatible things about whether the two human checkpoints can be
turned off.

- `CLAUDE.md`, `README.md`, and DEC-005 state that context approval and finding approval
  are structural rather than configurable.
- `docs/architecture/data-model.md` section 6 makes `require_context_review` and
  `require_finding_review` **required booleans** on `AssessmentConfiguration`, which is by
  construction a switch for turning them off.
- `docs/architecture/evaluation-plan.md` section 14 proposes "human checkpoint vs no
  checkpoint" as a workflow comparison, which needs that switch to exist.

An implementer building either checkpoint cannot tell whether the field is authoritative,
vestigial, or evaluation-only. Four separate research passes over this corpus reached this
contradiction independently, which is a signal that it will be hit early and often.

## Scope

### Options

1. **Remove both fields from `AssessmentConfiguration`.** Checkpoints become unconditional
   and the section 14 comparison is performed another way or dropped. Cleanest against
   DEC-005; costs an evaluation capability the plan asked for.
2. **Retain but constrain.** The fields exist and validate to `true`; they are honoured
   only under an explicit evaluation mode that is unreachable from an ordinary run and
   that marks the resulting assessment non-authoritative. Preserves both DEC-005 and the
   ablation.
3. **Retain as free configuration.** This is a change to DEC-005 and requires amending it
   rather than quietly reinterpreting it.

### Decision criteria

- Can an evaluation run supply pre-recorded reviewer decisions without disabling the
  checkpoint node? A checkpoint that is bypassed and a checkpoint that is answered
  non-interactively are different things, and only the second preserves DEC-005.
- Is the guarantee enforceable at the type level, so no configuration value, environment
  variable, or function argument can advance the pipeline past an unapproved checkpoint?
- Does an ablated run record that it was ablated, so a result can never be mistaken for a
  normal one?

## Out of scope

- Implementing either checkpoint. This decision unblocks both.
- The pause and resume mechanism, which is DX-07.
- What is displayed at each checkpoint, which is DX-07.
