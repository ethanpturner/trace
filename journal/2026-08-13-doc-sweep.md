the same: the code had outrun the docs, and the docs now say what runs.

## The observation worth keeping

Every stale claim under-sold the project. That is the unusual failure mode — docs that rot
optimistic are common, docs that rot pessimistic mean the discipline ("present indicative only
for what runs today") was applied at writing time and never revisited. The threat model even
contained its own revisit trigger; what was missing was anyone acting on it. The audit that
found all this is repeatable, which is the better fix than any single sweep.
