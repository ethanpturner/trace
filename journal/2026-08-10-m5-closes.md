# M5 closes: the OWASP survey lands, and the benchmark stops being one scenario

M5 Alignment is done — all eight issues closed, seven of them in this session (#221's citation
resolver had landed earlier). The milestone existed to reconcile the project with the OWASP
landscape survey of 2026-08-10, and the reconciliation ran in both directions: where the corpus
had drifted from the ecosystem the docs were corrected, and where the ecosystem corroborated the
corpus the corroboration was recorded rather than left as private conviction.

## The renumbering problem, handled by pinning rather than chasing

The GenAI LLM Top 10 2026 (published 2026-08-04) renumbered two of the four categories the
threat vocabulary cites: Improper Output Handling moved LLM05→LLM10, Unbounded Consumption
LLM10→LLM06. The fix was never to update to the new numbers — the catalog's 2025 citations are
version-pinned and remain correct provenance — but to make every unqualified reference
year-qualified, because a bare "LLM05" now names different risks in adjacent releases (#219).
The same instinct drove #222: ASVS's own README prescribes `v5.0.0-2.1.1` as the citation form
precisely because identifiers do not survive releases, so the catalog adopted it, and the
resolver now refuses to vouch for any release other than the one it holds. Whether catalog 0.2
adopts the 2026 identifiers stays an M0 decision, deliberately not made here.

## Verify, then write

Three findings from checking the issue bodies against their sources rather than transcribing
them:

- The ASVS "every chapter has an X.1 Documentation section" claim was wrong in the flattering
  direction — it is 11 of 17, verified against the cached export, and every chapter the catalog
  cites is among the eleven (#220). The blanket claim would have misled whoever extends the
  catalog into V4/V10/V12 territory.
- The ASI Agentic Top 10 terms in #223's sketch did not match the published titles: ASI06 is
  Memory *and Context* Poisoning, and `excessive_agency` turned out to be an LLM-list category,
  not an ASI one. The constants record the published titles.
- The AIVSS license really is SPDX `NOASSERTION`, confirmed via the API before citing it in the
  checkpoint-2 severity rubric references (#224) — so it is cited by name and URL with nothing
  reproduced, and its own ordinal-scale caveat is carried with it.

## DEC-041 pays for itself

Extending the vocabulary constants (#223) cost nothing and risked nothing because the constants
validate nothing — the DEC-036/DEC-041 posture meant four new taxonomies (LLM 2026, ASI 2026,
Cumulus's suits, SP 800-30's threat sources) became documentation, and the validation node's
existing unfamiliar-category observation covers them without a behavioral change. The husky-ai
source model then used `sources: ["adversary"]` — the SP 800-30 split, in the wild, in the same
session it was recorded.

## The benchmark stops being one scenario

The largest delivery is #225: three scenarios join ForgeFlow in the registry, each seeded from
an externally authored model so the truth set arrives independently written rather than invented
alongside the inputs — the authorship question DEC-028 left open, answered by borrowing peer
review. The split discipline held throughout: the source's *system description* became `input/`,
its *threat list* became `expected-threats.yaml`, and for husky-ai the controls the source marks
`suggested` are deliberately absent from the inputs, because they are reviewer recommendations
rather than the deployed system — which makes their absence DEC-009 ground, not an authoring
gap. The invoice-agent scenario is the first whose subject is itself an LLM agent, and its
source repo's unasserted license forced the same cite-by-URL, reproduce-nothing posture as
AIVSS.

Two stale notes surfaced while registering: ForgeFlow's registry status and CLAUDE.md both still
said its truth set was unauthored, months of milestones after M2–M4 authored it. Corrected in
the same PR.

## Positioning, recorded once

#226 wrote down what had been implicit: DEC-009 now carries dated external corroboration from
three independent sources; the pipeline is mapped onto the Four Question Framework in
current-architecture.md section 2.7; and vocabulary.py documents why the cross-methodology
crosswalk is documentation rather than a normalization rule — LINDDUN and PLOT4ai share two
category names with different meanings, so a term-level mapping table would silently decide
cases it was never shown.
