## Context

DEC-007 is the only entry in `docs/architecture/decision-log.md` not marked Accepted.
`langgraph`, `langchain`, `langchain-anthropic`, and `langchain-openai` are declared in
`pyproject.toml` and imported nowhere. `CLAUDE.md` warns explicitly against describing the
project as built on LangGraph.

The orchestrator owns the properties that are structural rather than optional: pausing at
two human checkpoints (DEC-005), bounded retries, loop prevention, execution limits, and
resumable runs (`current-architecture.md` section 5.3, `agent-design.md` sections 26 and
27). Leaving this open until the first checkpoint is built means either building pause and
resume twice, or adopting LangGraph by default and calling it a decision afterwards.

## Scope

### Options

1. **Accept LangGraph.** Gets checkpointing, interrupt and resume, and graph
   visualization. Costs a framework dependency across the pipeline, a second state
   representation alongside the domain objects, and the risk that its checkpointer becomes
   a second authoritative store — which collides directly with DEC-006 and with "the
   application owns all authoritative state."
2. **Plain Python functions with an explicit state machine.** A `WorkflowRun` row plus a
   permitted-transition table is enough for a fixed, linear, thirteen-node pipeline with
   two pause points. Resume is a database read, not a checkpointer. Costs: retries,
   limits, and visualization are hand-written.
3. **A durable-execution engine such as Temporal or Prefect.** Ruled out by DEC-004's
   local single-user constraint; both want a server.
4. **Direct LangChain chains.** Gives model plumbing without workflow control, which is
   the half that is already easier.

### Decision criteria

- Does the framework improve pause and resume over a `WorkflowRun` row and a transition
  table, for a **fixed, linear, thirteen-node** pipeline?
- Can execution limits be enforced by the application rather than by the framework?
  `agent-design.md` section 27 assigns them to the orchestrator.
- Does the checkpointer become a competing authoritative store? If so, DEC-006 is violated.
- Roadmap Stage 6 lists "why LangGraph was or was not retained" as an interview story.
  Either answer is acceptable; an undecided answer is not.

## Acceptance criteria

- [ ] DEC-007 is moved to Accepted, Rejected, or Superseded, and an entry records the
      reasoning.
- [ ] `current-architecture.md` sections 5.3 and 14 and the `README.md` technology table
      are updated to match.
- [ ] If LangGraph is rejected, `langgraph` and any unused `langchain*` packages are
      removed from `pyproject.toml` and `uv.lock` is regenerated so `uv sync --locked`
      still passes.
- [ ] If accepted, the entry states explicitly where authoritative state lives and that
      the checkpointer is not it.
- [ ] The entry states how the five execution ceilings are enforced and by which component.

## Out of scope

- The pause and resume mechanism's user-facing shape, which is DX-07.
- Implementing the orchestrator, which is an M2 issue.
- Model client construction, which is DX-05.
